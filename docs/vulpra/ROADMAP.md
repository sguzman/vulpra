## ✂️ M3 — User-specific debloating

**Status: in progress, 2/6 acceptance gates (33%) complete.** The native M2 browser remains protected. Three independent selective **opt-in** packaged omissions have now passed native runtime and matched-size acceptance: Normandy recipe runner **27,620 B (0.032%)**, exactly two ASRouter AI promotion modules **3,184 B (0.00366%)**, and New Tab AdsFeed **7,120 B (0.00817%) in the guarded pair**, versus **219,360 B (0.251711%) in the earlier independent source-matched pair**. Source blob reduction is not compiled binary saving. The normal build still includes optional modules; four broad M3 gates remain open.
